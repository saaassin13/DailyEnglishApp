# 每日英语学习APP

基于Flutter开发的英语单词学习应用，支持多词库选择、智能复习、学习记录等功能。

## 页面功能

### 1. 词库页面（WordbookSelectionScreen）
- 显示8个预定义词库（小学、中学、高中、四级、六级、考研、托福、SAT）
- 选择当前学习词库
- 显示词库学习进度（熟悉/不熟/未选）
- 设置每日学习量
- 显示待复习、待新学、新词待选数量
- 支持重置词库功能

### 2. 学习详情页面（StudyDetailScreen）
- 显示单词详情（单词、音标、释义、短语、例句）
- 支持美式/英式发音播放
- 点击屏幕显示/隐藏翻译
- 标记单词状态：记住/不熟/不会
- 实时显示今日学习时长
- 学习完成后显示统计信息

### 3. 签到页面（CheckInScreen）
- 日历视图显示每日学习完成状态
- 支持切换月份查看历史记录
- 绿色圆点标记已完成日期
- 今日日期高亮显示

### 4. 个人中心页面（ProfileScreen）
- 显示用户名（可编辑）
- 统计信息：连续签到天数、累积签到天数、累积学习时长
- 已记住的单词量
- 平均每日学习单词量
- 主题设置（预留）
- 版本信息（预留）

## 技术模块

### 核心框架
- **Flutter** - 跨平台UI框架
- **Provider** - 状态管理

### 功能模块
- **SharedPreferences** - 本地数据持久化（用户设置、学习记录）
- **AudioPlayers** - 音频播放（单词发音）
- **HTTP** - 网络请求（有道词典发音API）
- **Path Provider** - 文件路径管理

### 核心算法
- **艾宾浩斯遗忘曲线** - 智能复习算法，根据记忆状态计算复习间隔
